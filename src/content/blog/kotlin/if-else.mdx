## if-else

`if-else` 用于结果判断

```kotlin
val score = 2
val res = if (score > 2) "yes" else "no"
```

另一种写法

```kotlin
val res = if (score > 2) {
    "yes"
} else {
    "no"
}
```


## when

`when` 用于多分支判断

```kotlin
val score = 2
val res = when (score) {
    1 -> "A"
    2 -> "B"
    3 -> "C"
    else -> "D"
}
```

`when`  多条件和范围语法判断

```kotlin
val score = 2
val res = when (score) {
    1, 2 -> "A"
    3, 4 -> "B"
    in 5..10 -> "C"
    else -> "D"
}
```
